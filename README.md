# 🏨 Hotel Booking Cancellation Prediction

A machine learning web application that predicts whether a hotel booking will be **canceled or not** based on booking information.  
This project uses a **LightGBM classification model with hyperparameter tuning** and is deployed using **Streamlit**.

---

# 📌 Project Overview

Hotel booking cancellations can significantly impact hotel revenue and operational planning.  
This project aims to build a predictive model that helps hotels **identify high-risk bookings** so they can take preventive actions.

The model analyzes booking details such as:

- Lead time
- Customer type
- Market segment
- Booking history
- Special requests
- Room type
- Stay duration
- And other booking-related features

The final output predicts whether a booking is **likely to be canceled** along with the **probability of cancellation**.
